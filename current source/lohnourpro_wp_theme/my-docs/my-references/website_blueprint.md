# Lohnour Pro
# Website Blueprint
Version: 1.0

---

# 1. Objective

Build a modern, minimal, high-performance business website for Lohnour Pro.

The website should serve two primary audiences:

- Organizations looking for AI Training.
- Individuals interested in learning AI.

The website should primarily function as a lead generation platform while establishing authority in AI Training.

---

# 2. Website Structure

The website should initially include the following pages.

## Home

Landing page introducing the company.

---

## About

Information about Lohnour Pro and its founder.

---

## Services

Overview of all AI training offerings.

Each service should have its own dedicated page.

---

## Corporate Training

Dedicated landing page for organizations.

Should explain:

- Training formats
- Benefits
- Industries served
- Typical engagement process
- Call-to-action

---

## Workshops

Display upcoming and past workshops.

Each workshop should have its own page.

---

## Blog

Educational articles related to AI.

Organized using WordPress Categories and Tags.

---

## Contact

Company contact details.

Enquiry form.

Social links.

---

## Privacy Policy

---

## Terms & Conditions

---

## 404 Page

Simple branded error page.

---

# 3. Homepage Layout

The homepage should contain the following sections.

1. Hero Section

2. About Lohnour Pro

3. Services Overview

4. Why Choose Lohnour Pro

5. Corporate Training

6. Workshops

7. Testimonials

8. Latest Articles

9. Call To Action

10. Footer

The exact visual design can evolve, but the content hierarchy should remain focused on building trust and generating enquiries.

---

# 4. Navigation

Primary navigation should remain simple.

Suggested menu:

- Home
- About
- Services
- Corporate Training
- Workshops
- Blog
- Contact

Primary CTA:

Book a Consultation

---

# 5. Content Types

Use WordPress Pages for static content.

Use WordPress Posts for blogs.

Create Custom Post Types only where they provide meaningful organizational value.

Suggested Custom Post Types:

- Services
- Workshops
- Testimonials
- Clients
- Case Studies

Do not create unnecessary Custom Post Types.

---

# 6. Taxonomies

Use native WordPress Categories and Tags for blog content.

Create custom taxonomies only when necessary.

Possible custom taxonomies include:

- Industries
- Audience
- Skill Level

Avoid excessive complexity.

---

# 7. Components

The following reusable components should be available throughout the website.

- Header
- Navigation
- Footer
- Hero
- Buttons
- Cards
- Section Heading
- Testimonial Card
- CTA Banner
- FAQ
- Contact Form

Components should be reusable across pages.

---

# 8. Forms

The website should include:

## Contact Form

General enquiries.

---

## Corporate Training Enquiry

For organizations interested in training.

Fields should include:

- Name
- Organization
- Email
- Phone
- Organization Size
- Training Requirement
- Message

---

Forms should integrate cleanly with WordPress.

---

# 9. Blog

The blog should support:

- Categories
- Tags
- Featured Images
- Search
- Related Articles
- Author Information
- Social Sharing (optional)

The blog is an important long-term content marketing asset.

---

# 10. Call-to-Actions

The website should consistently encourage visitors to take action.

Primary CTAs include:

- Book Consultation
- Request Corporate Training
- Contact Us

CTA placement should feel natural rather than intrusive.

---

# 11. Future Expansion

The architecture should allow future addition of:

- Courses
- Learning Portal
- Membership
- Community
- Resources Library
- AI Consulting
- AI Implementation

These features do not need to be built now, but the architecture should not prevent them.

---

# 12. Design Direction

The visual identity should reflect the Lohnour Pro brand.

Keywords:

- Minimal
- Premium
- Professional
- Modern
- AI-inspired
- Elegant
- High whitespace
- Black & White
- Clean typography
- Subtle micro-interactions

Avoid unnecessary visual clutter.

---

# 13. Success Criteria

The completed website should:

- Clearly communicate what Lohnour Pro does.
- Appeal to both B2B and B2C audiences.
- Generate qualified enquiries.
- Be easy to update through WordPress.
- Load quickly.
- Be responsive across devices.
- Provide a solid foundation for future business growth.
